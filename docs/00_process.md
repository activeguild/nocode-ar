# 開発プロセス

本プロジェクトは「ノーコードARサービス」を、以下の3つの役割に分かれて進める。

| 役割 | 責務 | 成果物 |
| --- | --- | --- |
| マーケター | 市場調査、PMF（Product Market Fit）に向けたサービス要求の定義、要件レビュー | `docs/01_market_research.md`, `docs/02_service_requirements.md`, `docs/03_review_log.md` |
| 開発者 | 要求からの要件定義、技術選定、実装 | `docs/03_requirements_spec.md`, `docs/04_architecture.md`, ソースコード |
| QA | テスト計画、検証、不具合報告 | `docs/05_qa_report.md` |

## フロー

1. マーケターが市場を調査し、PMF に向けたサービス要求（要求仕様）を作成する。
2. 開発者が要求から要件定義を作成し、マーケターにレビューを依頼する。
3. マーケターがレビューし、指摘があれば開発者が修正する。マーケターから **GO** が出るまで 2〜3 を繰り返す。
4. GO が出たら開発者が実装を進める。
5. 実装完了後、QA が検証する。問題があれば開発者が修正し、QA が再検証する。
6. QA で問題がなければ、オーナー（人間）が最終確認する。

## 共通ルール

- ドキュメントは日本語で記述する。
- 各フェーズの成果物は `docs/` 配下に Markdown で残す。
- レビューのやりとりは `docs/03_review_log.md` に時系列で記録する。
