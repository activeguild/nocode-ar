# ここほれワンワン（ブラウザ試作）

犬を相棒に畑を掘り、120秒でいちばん稼いだ人が勝つ「財宝争奪戦」の試作です。
Steam / Roblox 向けに作る前に、ルールが面白いかをブラウザで確かめるためのものです。
同じリポジトリの AR サービスとは独立していて、依存パッケージはありません（Node.js 22 以上）。

## 遊び方

```bash
cd games/kokohore-wanwan
node server.mjs          # http://localhost:8787
```

- **CPUと対戦**: ひとりで CPU 3人と対戦（ブラウザ内で完結）
- **友だちと対戦**: 同じ合言葉を入れた人が同じ部屋に入る（最大8人、4人に足りない分は CPU）
- 移動 `WASD` / 矢印、掘る `Space`（押しっぱなし）、スキル `E`。スマホは畑をなぞって移動

`node build-single.mjs` で、サーバなしで開ける1枚の HTML（CPU対戦のみ）を `dist/` に出力します。

## ルール

| | 得点 | 掘る時間 |
|---|---|---|
| 小判 | 10 | 0.9秒 |
| つぼ | 30 | 1.4秒 |
| 千両箱 | 100 | 2.6秒 |
| ハチの巣 | 0（2.5秒動けない） | 0.9秒 |

- 財宝の場所は見えない。**犬の鼻**が 4 段階（クンクン → ワン！ → ワンワン！ → ここほれ！）で近さを教える
- 掘りかけの量はマスに残る。途中で離れると、あとから来た人が仕上げて持っていく
- 6秒ごとに小判かつぼが1つ湧く。残り30秒で千両箱が3つ追加される

| 犬 | スキル | 効果 | 待ち時間 |
|---|---|---|---|
| 柴犬 | ここほれレーダー | 5秒間、近くに埋まっている物（ハチの巣も）が見える | 14秒 |
| ブルドッグ | 大ほえ | 近くの相手を1.6秒止め、掘るのを中断させる | 15秒 |
| ダックスフンド | 高速ほり | 5秒間、掘る速さが3倍 | 14秒 |
| ボーダーコリー | よこどり | 近くの相手から得点の10%（最低10）をうばう | 22秒 |

## 構成

- `public/sim.js` — ルール本体。描画や通信に依存しないので、数値調整も移植もここを見ればよい
- `public/client.js` `index.html` `style.css` — 画面と操作
- `server.mjs` — オンライン対戦サーバ。状態はサーバが持ち、財宝の場所はクライアントに送らない
